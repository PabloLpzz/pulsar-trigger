# Pulsar R50 experimental APK

Download [pulsar-r50-liveview-experimental.apk](pulsar-r50-liveview-experimental.apk) using GitHub’s **Download raw file** button.

This debug-signed build installs as **Pulsar R50 Test** (`com.ehrocha.pulsar.r50test`), version `0.649.0-r50-liveview`, alongside the existing app.

The build includes the Canon EOS Live View property-write fallback for USB PTP and Wi-Fi PTP/IP. All 244 Android unit tests passed. Physical R50 validation is still pending.

See the [test guide](../../docs/r50-live-view-test.md). The adjacent `.sha256` file contains the APK checksum.
